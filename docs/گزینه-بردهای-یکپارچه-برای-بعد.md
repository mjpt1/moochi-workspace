> - **PCF85063** RTC + هدر باتری مجزای RTC

> - **ME6217C33M5G** رگولاتور، حداکثر ۸۰۰mA
> - آنتن سرامیکی + کانکتور IPEX برای آنتن خارجی
> - دکمه‌های RESET، BOOT، تنظیم صدا، و کنترل تغذیه‌ی باتری

## چرا این ایده مطرح شد

بردهای «همه‌چیز روی یک برد» پردازنده و نمایشگر و تاچ را یکجا دارند. برای ربات **ثابت** یعنی تقریباً هیچ لحیم‌کاری لازم نیست و ظرف یک هفته می‌شود چیزی زنده داشت.

**این‌ها جایگزین ربات تانکی نیستند.** برای آن پروژه به ۱۸ تا ۲۱ پین نیاز است (نمایشگر SPI، I2C، دو I2S، دو تاچ، LDR، درایور موتور) و هیچ‌کدام از این بردها این تعداد پین آزاد ندارند. ضمناً در ربات با سر متحرک، نمایشگر باید جدا از برد اصلی و روی سر باشد — در این بردها نمایشگر روی همان PCB لحیم شده و جدا نمی‌شود.

از ویکی رسمی تایید شد:

- **ESP32-S3** دو هسته ۲۴۰MHz · ۵۱۲KB SRAM · **۲MB PSRAM** · **۱۶MB فلش**
- نمایشگر **۱.۲۸ اینچ گرد** IPS، ۲۴۰×۲۴۰، تاچ **خازنی** (CST816S)
- **QMI8658** — شتاب‌سنج و ژیروسکوپ ۶ محوره روی برد
- **هدر شارژ و دشارژ باتری لیتیومی ۳.۷ ولت روی برد**
- GPIO1 ولتاژ باتری را می‌خواند (تقسیم مقاومتی ۲۰۰K/۱۰۰K) → ربات می‌فهمد شارژش کم است
- USB Type-C
- بسته: برد + کابل SH1.0 دوازده‌پین

### ⭐ پین‌های آزاد — عدد قطعی از جدول ویکی

کانکتور SH1.0 دقیقاً **۶ پین** بیرون می‌دهد:

```
GPIO15 · GPIO16 · GPIO17 · GPIO18 · GPIO21 · GPIO33
```

قابل تنظیم برای I2C، SPI و غیره. ضمناً VSYS روی همین کانکتور می‌تواند ۵ ولت ورودی بگیرد.

**یعنی صدا شدنی است:** I2S برای MAX98357 خودمان ۳ پین می‌خواهد (BCLK، LRC، DIN) و ۳ پین هم باقی می‌ماند.

### پین‌های اشغال (برای مرجع)
| GPIO | کاربرد |
|---|---|
| 0 | BOOT |
| 1 | ADC ولتاژ باتری |
| 2 | نور پس‌زمینه LCD |
| 3، 4 | INT2، INT1 ژیروسکوپ |
| 5 | وقفه تاچ |
| **6، 7** | **I2C — SDA و SCL** (ژیروسکوپ و تاچ روی همین باس) |
| 8–14 | نمایشگر و تاچ (DC، CS، CLK، MOSI، MISO، RST) |

### ❌ چه ندارد
صدای داخلی · LDR · (کارت SD تایید نشده)
