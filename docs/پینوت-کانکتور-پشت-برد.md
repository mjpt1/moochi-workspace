# پینوت کانکتور پشت برد (J7)

> از شماتیک رسمی Waveshare استخراج شد، نه از روی عکس یا حدس.
> منبع: `files.waveshare.com/wiki/ESP32-S3-Touch-LCD-1.85C/ESP32-S3-Touch-LCD-1.85C-Schematic.pdf`

کانکتور `J7` روی پشت برد، ۲۸ پین (۲ ردیف × ۱۴).

## جدول کامل

| پین | سیگنال | پین | سیگنال |
|---|---|---|---|
| ۱ | USB 5V | ۲ | BAT |
| ۳ | GND | ۴ | GND |
| ۵ | ☠️ USB D− (`GPIO19`) | ۶ | **SCL — `GPIO10`** |
| ۷ | ☠️ USB D+ (`GPIO20`) | ۸ | **SDA — `GPIO11`** |
| ۹ | **3V3** | ۱۰ | **3V3** |
| ۱۱ | **GND** | ۱۲ | **GND** |
| ۱۳ | GPIO0 | ۱۴ | TX (`GPIO43`) |
| ۱۵ | GPIO1 | ۱۶ | RX (`GPIO44`) |
| ۱۷ | GPIO3 | ۱۸ | GPIO13 |
| ۱۹ | GPIO4 (وقفه‌ی لمس) | ۲۰ | GPIO12 |
| ۲۱ | GPIO6 | ۲۲ | EXIO8 |
| ۲۳ | GPIO7 | ۲۴ | EXIO7 |
| ۲۵ | GPIO8 (ولتاژ باتری) | ۲۶ | EXIO6 |
| ۲۷ | GPIO9 | ۲۸ | EXIO5 |

## تطبیق با برچسب پشت برد

برچسب دو ستون دارد. از **پایین به بالا**:

- **ستون چپ** = پین‌های **زوج**: `BAT, G, SCL, SDA, 3V3, G, TX, RX, 13, 12, E8, E7, E6, E5`
- **ستون راست** = پین‌های **فرد**: `5V, G, 19, 20, 3V3, G, 0, 1, 3, 4, 6, 7, 8, 9`

دقیقاً با جدول بالا می‌خواند.

## ☠️ تله

برچسب در دو ردیف می‌نویسد `SDA | 20` و `SCL | 19`.

آن `20` و `19` **پین‌های USB هستند**، نه یک باس I2C دوم. اگر اشتباهی رویشان سیم بزنی، ارتباط USB قطع می‌شود و آپلود از کار می‌افتد. راه برگشت: BOOT را نگه دار → یک بار RST → BOOT را ول کن.

این همان اشتباهی است که یک بار در کد کردیم (`Wire1.begin(20,19)`) و فرمور، کابل USB خودش را قطع کرد.

## چطور بفهمی کدام ردیفِ فیزیکی، ستونِ زوج است

شماتیک می‌گوید پین ۶ و ۸ کدامند، ولی نمی‌گوید پین ۱ سمت چپ است یا راست.

**راه اول — علامت پین ۱.** روی خود کانکتور معمولاً یک مثلث ریز، نقطه، یا گوشه‌ی مربعی هست. پین ۱ و ۲ همان انتهایی است که روی برچسب `BAT | 5V` نوشته شده.

**راه دوم — مولتی‌متر (قطعی و بی‌خطر).** روی برد یک مقاومت ۱۰ کیلواهمی بین `SDA` و `3V3` هست (`R45` در شماتیک). روی پین‌های USB چنین چیزی نیست.

۱. کابل USB را بکش
۲. مولتی‌متر روی اهم، محدوده‌ی ۲۰ کیلو
۳. یک پروب روی سوراخ `3V3`
۴. پروب دیگر روی یکی از دو سوراخِ ردیف `SDA`

- **حدود ۱۰ کیلواهم** → ستون درست است
- **عدد خیلی بزرگ یا هیچی** → آن `GPIO20` است، ستون دیگر را بزن

## سیم‌کشی MPU6050

| پایه‌ی ماژول | به کدام پین |
|---|---|
| `VCC` | ۹ یا ۱۰ (3V3) — هر دو ستون یکی است |
| `GND` | ۳، ۴، ۱۱ یا ۱۲ — هر دو ستون یکی است |
| `SDA` | **۸** |
| `SCL` | **۶** |
| `AD0` | خالی بگذار → آدرس `0x68` |

آدرس `0x68` با هیچ‌کدام از دستگاه‌های روی باس (`0x15`, `0x18`, `0x20`, `0x40`, `0x51`) تداخل ندارد.

**هیچ تغییری در کد لازم نیست** — کد از قبل `0x68` را روی باس اصلی می‌گردد. `USE_SECOND_BUS` باید صفر بماند.

## تایید بعد از سیم‌کشی

در Serial باید ببینی:

```
   باس اصلي (SDA=11 · SCL=10):
      0x15
      0x18
      0x20
      0x40
      0x51
      0x68      ← تازه
   ✅ شتاب‌سنج: MPU6050 @0x68 (باس اصلي)
```

## نکته‌ی عملی

فاصله‌ی سوراخ‌های این کانکتور طبق شماتیک **۱.۲۷ میلی‌متر** است — نصفِ فاصله‌ی معمولی. سیم‌های جامپر استاندارد داخلش نمی‌روند.

## درس

اول از روی عکس حدس زدم که کدام سوراخ کدام است. کاربر پرسید «تو شماتیک خود تولیدکننده این‌ها نیست؟» و بود — کامل و بدون ابهام.
